# CIVIC-SHIELD

Urban Emergency Decision Support and Evacuation System.

The project contains a Java implementation and a fully interactive browser interface. The website accepts user-entered emergency details, automatically calculates priority, maintains a priority queue, supports exact resource quantities through dropdowns, finds region-to-region safe routes using shortest-path analysis, and provides simple What-If scenarios for new users.

## Website
Open `website/index.html` in a browser, or publish the `website` folder with GitHub Pages.

## Java
`java/CIVICShield.java` is the academic Java implementation.

## Sustainable Development Goals
- Good Health and Well-being (3)
- Sustainable Cities and Communities (11)
- Climate Action (13)

This is an academic prototype and is not connected to live emergency services, GPS, traffic, weather, or government systems.
